# Query KMTNet Microlensing Events

This is to query archival and currently/alerted KMTNet microlensing events.
Information on how to run the code and what each file does can be found in notes.txt
The easiest (start to finish) run can be started by setting the following in run_XmatchKMT.py :
- obj_Name (a self selected name by the user)
- obj_ra (RA in deg)
- obj_dec (Dec in deg)
